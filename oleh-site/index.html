02 → systems I've built

Agent-scale product security

AI vulnerability verifier

A multi-agent system that validates findings by actually exploiting them: it spins up an isolated sandbox, runs AI-driven DAST against the live target, and reproduces the bug rather than guessing from context. Only what reproduces reaches a human.

Automated remediation bot

Goes from validated finding to root cause to fix. It traces the vulnerability class, finds sibling instances, and proposes the patch as a PR with tests, behind human review gates. Well-understood classes get fixed, not just filed.

Bug bounty at volume

I've managed bug bounty programmes directly: scope, policy, researcher engagement, and the triage tooling behind them. Every resolved report feeds the automation, so the next thousand reports get cheaper to handle than the last.

Pipeline security, owned

Whoever wrote that job description is a genius

"Adding more triagers doesn't close that gap."
Most honest line I've read in a security posting. No changes requested.

I'm not nodding along politely here, I share this vision completely. It's how I already work. The industry's answer to every security problem is another third-party vendor, and every one of them scans your code knowing nothing about it. No idea what your auth model is, which routes are tenant-scoped, what shipped yesterday. So they flag everything, engineers trust nothing, and you're paying six figures for noise you're locked into.

The unlock is building it in-house, where your tooling gets what no vendor ever will: full context enrichment. Your agents read the actual codebase, the auth flows, the deploy history, the past incidents. That's the difference between "possible IDOR, severity unknown" and "reproduced with a tenant-B token, root cause is a missing ownership check, here's the PR." Tailored beats generic, owned beats rented, and every resolved report makes your system smarter instead of a vendor's.

in-house > vendor lock-in · context-rich > signature matching · compounding > renewing the licence
